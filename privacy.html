Calvin - Privacy Policy

Last updated: 8 October 2026

Calvin is a private personal assistant used only by its developer, Sam Godfrey. It has one user: Sam. This policy describes how it handles data from Sam's Google account.

Data accessed

With Sam's consent, Calvin accesses Gmail, Google Calendar, Google Drive and Google Tasks in Sam's own account, to read and organise messages, events, files and to-dos, and to draft messages. Sending messages, deleting items others created, and sharing files each require Sam's explicit approval.

How data is used

Data is used only to carry out Sam's requests and scheduled routines (such as a daily briefing). It is processed by an AI model (Anthropic's Claude) to produce responses. It is not used for advertising and is not sold.

Storage and sharing

Access tokens are stored on a private server controlled by Sam. Google data is not shared with any third party other than the AI processing described above, and is not transferred to anyone else.

Google API Services User Data Policy

Calvin's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and contact

Access can be revoked at any time at myaccount.google.com/permissions. Questions: samjgodfrey1@gmail.com.
